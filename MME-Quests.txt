# =====================================================================
#  MME-Quests.txt  --  Completed-Quest reward definitions (format v2)
#  for the MMUD Explorer "Completed Quests" character panel.
# ---------------------------------------------------------------------
#  This is the SHIPPED DEFAULT set. It is recreated automatically if
#  missing, so behaviour is identical out of the box. Edit freely.
#
#  Per-realm additions/overrides go in MME-QuestsCustom.txt (same
#  format). A block there with the same Key overrides the built-in;
#  a block with a new Key is appended as a new quest in the list.
#
#  QUEST BLOCK
#    [Quest <id>]            id = built-in slot number (0..11) or any slug
#    Key    = <slug>         stable id used for save/paste (never reorder-broken)
#    Name   = <text>         shown in the list and in stat tooltips
#    Engine = both|stock|gmud
#    Choice = <comboField>   0..3 selects which option set; omit = simple quest
#    Import = <abil>:<min>   (optional) paste ability id that ticks this quest
#    Export = <abil>|<val>   (optional) ability emitted when exporting char
#    Reward = <terms>        simple quest
#    Option<k> = <label> | <terms>   choice quest, k = dropdown index
#
#  TERMS (comma separated)  <target>:<value>
#    sN  accy  accymax  dodge  str        (slot N or special target)
#    engine qualifier prefix: [stock] or [gmud]   (no prefix = both)
#  SLOTS: 2=AC 4=Encum 5=MaxHP 6=Mana 7=Crits 9=SC 11=MaxDmg
#         14=BSMin 15=BSMax 17=ManaRegen 19=Stealth
# =====================================================================
